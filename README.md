# 📚 Student Companion

## 🚀 Overview
Student Companion is a full-stack web application that helps students and administrators manage courses, assessments, and academic progress in one place. It simplifies organization and eliminates manual grade calculations.

## ✨ Features
- 🔐 Secure authentication (Student / Admin roles)
- 📊 Dashboard to track progress and assessments
- 📝 Manage courses, assignments, and evaluations
- ⚡ Automatic grade calculation
- 🔄 RESTful API for efficient data handling

## 🛠️ Tech Stack
- JavaScript, HTML, CSS
- Node.js, Express
- SQL
- Git

## 📊 How It Works
- Users log in as Student or Admin
- Admins create and manage courses and assessments
- Students track their progress and grades
- The system automatically calculates results

## 🎯 Purpose
This project was built to simplify academic management and demonstrate full-stack development skills including backend APIs, databases, and authentication systems.
